Vehicle Damage Detection

A YOLOv13-based detection system for identifying vehicle damage from image input and supporting faster inspection workflows.

Image Model Boxes Report

Purpose

Automating visual inspection with object detection.

The project explored how modern computer vision can support insurance and fleet inspection by detecting visible damage regions from images and turning visual input into structured signals for review. The research used a curated 4,000-image dataset and a data-centric filtering and augmentation pipeline.

Pipeline

From raw image to usable detection output.

Input

Vehicle images prepared for detection and analysis.

Model

YOLOv13 used to identify bumper, rear bumper, and windshield damage.

Output

Reached 0.789 mAP@0.5, 0.76 F1-score, and about 23 ms GPU inference.
