Vehicle Damage Detection

IEEE paper project using YOLOv13 to detect exterior vehicle damage for faster, more consistent insurance and fleet inspection workflows.

YOLOv13 4,000 labeled images 0.789 mAP@0.5 23 ms inference
Back to Projects
YOLOv13 analysis Damage regions detected in real time

Purpose

Automating visual inspection with object detection.

Manual vehicle inspection is slow and subjective. This research uses a two-stage, data-centric YOLOv13 pipeline to filter useful front/rear vehicle photos, detect visible exterior damage, and support faster claim or fleet review.

Paper Highlights

Short, measurable, deployment-minded.

Dataset

Curated and labeled 4,000 images across bumper, rear bumper, and windshield damage.

Pipeline

Filtered non-informative viewpoints and balanced classes using collection plus augmentation.

Result

Achieved 0.789 mAP@0.5, 0.76 F1-score, and about 23 ms GPU inference.
