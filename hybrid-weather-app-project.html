This project is a complete end-to-end weather intelligence system that combines real-time weather feeds and historical climate datasets, processes them through Kafka streaming pipelines, and stores them in TimescaleDB hypertables for fast time-series analytics. Everything runs inside Docker, making it easy to deploy and reproduce across environments.

Why I built this

To explore real-world data engineering workflows — stream processing, ETL, storage optimization, and analytics — and learn how multiple data sources can be unified for climate insights, comparisons, and future forecasting extensions.

Deep climate analytics using Apache Superset, powered by optimized TimescaleDB hypertables.

Explore trends, compare climate ranges across regions, and analyze historical vs real-time conditions — all backed by a scalable data pipeline.

What the system does

  • Fetches data from NASA POWER, local weather stations, and OpenWeather (live feed).
  • Streams million-record datasets into Kafka using Node.js producers.
  • Cleans and transforms data using Node.js Kafka consumers (ETL).
  • Stores time-series data in TimescaleDB hypertables for fast analytics.
  • Powers both an EJS dashboard (SSE live monitoring) and Superset dashboards.
  • Fully containerized with Docker Compose for easy deployment and scaling.

Highlights

  • Hybrid pipeline: real-time + historical climate datasets
  • Kafka-based streaming to handle high-volume records
  • Time-series optimized schema using hypertables
  • Realtime monitoring UI using SSE (Server-Sent Events)
  • Production-like local setup with Docker Compose
Want to extend it?

Next steps could include ML forecasting (ARIMA/LSTM), anomaly detection, alerting, and autoscaling Kafka/consumers for higher throughput.
